# Rohan Thurkapally — Portfolio

A responsive personal portfolio website built with plain HTML, CSS, and JavaScript.

## Files

- `index.html` — portfolio content and page structure
- `style.css` — responsive styling and animations
- `script.js` — mobile navigation, current year, and contact-email copy interaction
- `resume.pdf` — optional PDF file to add for the Resume button

## Run in VS Code

1. Extract the ZIP.
2. Open the `Rohan-Portfolio` folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

No build tools or npm installation are required.

## Before publishing

1. In `script.js`, replace `your-email@example.com` with your real public contact email.
2. Add your LinkedIn profile URL if you want it displayed.
3. Verify that the listed certifications and project descriptions match your records.
4. Add links to the IoT Smart Home project and certificates if you have public URLs.
5. Add a downloadable resume only after placing your current PDF in the project and linking it from the page.

## Publish with GitHub Pages

1. Create a GitHub repository named `rohan1-stack.github.io` for a user-site URL, or use any repository and enable Pages in its settings.
2. Upload `index.html`, `style.css`, `script.js`, and this README at the repository root.
3. Open repository **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, and save.
5. Wait for the Pages deployment to finish, then open the URL shown in Settings → Pages.

The site can also be hosted on Netlify or another static web host.
